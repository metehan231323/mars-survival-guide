#  Interplanetary Survival Guide: Martian Map & HUD
**NASA Space Apps Challenge 2026 - Antalya Team Project**

---

##  Project Objective
A hyper-localized survival and navigation interface for astronauts during Marswalks that preserves instant oxygen budgets, filters out dangerous steep slopes, and plots safe routes to the nearest natural shelter in the event of solar storms or radiation spikes.

---

##  Official NASA Datasets and Tools Used
Our project relies entirely on verified and open-source NASA data:
- **NASA Mars Trek (`https://trek.nasa.gov/mars/`):** Topographic elevation data (MOLA), HiRISE high-resolution surface imagery, and crater coordinate infrastructure.
- **Mars 2020 Perseverance Raw Images (`https://mars.nasa.gov/mars2020/multimedia/raw-images/`):** Calibration of rock formations, hazardous obstacles, and scientific sample targets on the Jezero Crater surface.
- **THEMIS & RAD Simulation:** Thermal layers and live radiation telemetry streams.

---

##  Technical Infrastructure & Technologies
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Mapping Engine:** Leaflet.js & OpenPlanetary Mars Basemap
- **UI Design:** In-helmet HUD (Heads-Up Display) simulation and scanline effects

---

## ⚙️ Setup and Execution
No external server installation is required for this project.
1. Clone or download this repository.
2. Open the `index.html` file in any modern web browser (Chrome, Edge, Firefox) to run the prototype.
